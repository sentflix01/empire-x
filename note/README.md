# Notes

Authoritative project documentation lives in `docs/`:

- Setup: `docs/ONBOARDING.md`
- Architecture: `docs/architecture/`
- API and database: `docs/backend/`
- Deployment and operations: `docs/operations/`

Do not add deployment, setup, architecture, or API instructions here. Keeping those in `docs/` avoids duplicated, conflicting guidance.
