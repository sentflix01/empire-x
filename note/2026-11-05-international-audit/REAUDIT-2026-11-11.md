## 8. Regression tests to add

1. **Text limits (API):** each create/update route rejects one character over its limit with 422 (Jest/supertest).
2. **Signed-in axe:** extend `e2e/a11y` to `/analytics`, `/referral`, `/wallet`, `/business/inventory`, `/privacy`, `/feed`, signed in.
3. **Production drift:** add `/api/flags/page-guided-tours == decided value` and "no localhost in CSP" to `scripts/prod-verify.cjs`.
4. **Overlap:** at 375 px, `document.elementFromPoint` at the Terms link, the composer send button and an order price returns that element, not a floating launcher.
5. **i18n ratchet:** count literal JSX strings per file, failing CI when a file's count rises (same pattern as `strict-baseline.json`).

Starter for (1):

```ts
// backend/__tests__/textLimits.test.ts (after the fix)
it.each([
  ['POST', '/api/products', { title: 'x'.repeat(201), price: 1, stock: 1 }],
  ['POST', '/api/posts', { content: 'x'.repeat(5001) }],
  ['POST', '/api/businesses', { business_name: 'x'.repeat(101), business_category: 'retail' }],
])('%s %s rejects over-long text', async (method, path, body) => {
  const res = await request(app)[method.toLowerCase()](path).set(auth()).send(body);
  expect(res.status).toBe(422);
});
```
