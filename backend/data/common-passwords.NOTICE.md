# common-passwords.txt

Passwords of 8 to 128 characters from the zxcvbn common-password dictionary,
in order of frequency (17,950 entries). Used by `lib/passwordPolicy.ts` to
reject common passwords (audit F-017, OWASP ASVS 5.0 V6.2).

Source: `src/passwords.json` in the npm package `@zxcvbn-ts/language-common`
3.0.4 (data only; the package's code is not used), derived from zxcvbn.
