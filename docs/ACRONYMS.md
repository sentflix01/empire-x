## Usage Rules

1. **Always define on first use** in any document:
   Write `API (Application Programming Interface)` the first time it appears.
   After that, `API` alone is fine within the same document.

2. **List all acronyms at the top of each document** under an `## Acronyms` section
   — only include acronyms that actually appear in that document.

3. **Update this master list** when a new acronym is introduced anywhere in the project.

4. **Avoid creating new acronyms** unless necessary.
   Always prefer the full form in document titles and headings.
