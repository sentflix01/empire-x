Bugfix work implementing: **one provider rule for every email; Resend failures fall back to SMTP (#136)**

## 2. Why does it exist?

Login codes, password resets and order emails used Resend whenever
RESEND_API_KEY was set, with no fallback, so a broken or leftover key
stopped them silently. Digest emails tried Resend even with no key
("API key is invalid" in the logs). Now every email: Resend only when its
key is set, falling back to SMTP (e.g. Gmail) if it fails; otherwise SMTP.
