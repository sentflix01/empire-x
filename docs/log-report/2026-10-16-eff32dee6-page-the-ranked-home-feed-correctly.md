## 2. Why does it exist?

first page forever. The ranked feed also paged by created_at although it
orders by score, which would skip or repeat posts.
- Ranked feed cursor is "<snapshot ISO>|<offset>": every page scores
  against the same snapshot and only includes posts created before it.
  Old timestamp-only cursors still work; malformed ones get 400.
