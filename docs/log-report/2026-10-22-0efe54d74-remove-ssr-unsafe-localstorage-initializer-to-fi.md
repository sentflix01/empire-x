Bugfix work implementing: **remove SSR-unsafe localStorage initializer to fix stale-state race**

## 2. Why does it exist?

The useState lazy initializer ran during SSR where localStorage is
unavailable, silently returning false. On the client, if AiAssistant
mounted before PageGuide's useEffect fired and wrote the flag, the
initializer also read false — leaving the floating launcher hidden
until the custom event arrived (if it ever did).
Fix: start from false (SSR-safe), then after mount read localStorage
