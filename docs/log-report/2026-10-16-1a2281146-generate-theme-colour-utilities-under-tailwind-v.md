## 2. Why does it exist?

Tailwind v4 never loads tailwind.config.js (globals.css has no @config),
so bg-card, bg-primary, text-muted-foreground, border-border, bg-popover
and the rest were never generated. Every card, popover, overlay and the
default shadcn Button rendered transparent, in production too.
Declare the shadcn tokens in an `@theme inline` block so utilities
reference hsl(var(--token)) directly and the existing `.dark` overrides
