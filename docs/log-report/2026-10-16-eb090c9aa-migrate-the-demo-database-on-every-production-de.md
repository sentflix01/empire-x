## 1. What was this task?

CI/CD work implementing: **migrate the Demo database on every production deploy**

## 2. Why does it exist?

Demo sessions query a separate Demo database with the same SQL as Real, but
deploys only migrated Real. After the site-visibility release, the posts feed
and trending queries reference columns the Demo DB never received, so Demo
visitors got 500s on /api/posts and /api/trending.
The migrate job now runs db/migrate-demo.js right after the Real migrations
when the DEMO_DATABASE_URL secret is set (skipped with a notice otherwise).
