Bugfix work implementing: **load saved items once instead of looping (F-040)**

## 2. Why does it exist?

The Bookmarks page re-ran its load effect whenever `savedIds` changed.
For a user with no bookmarks each successful load stored a new empty
object, which re-triggered the effect: about 178 GET /api/saves per
second. In production that trips the 500-requests-per-15-minutes limit
within seconds and locks the user (and anyone sharing their IP) out of
the whole app.
