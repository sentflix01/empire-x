## 2. Direct Competitors

### 2.1 Shopify

| Dimension | Shopify | Nodbusiness | Advantage |
|-----------|---------|-------------|-----------|
| **Core Focus** | Pure commerce (online store) | Social + Commerce + Showroom | **Nodbusiness** |
| **Website Builder** | Basic (Online Store 2.0) | Full no-code builder (sections, themes, PWA) | **Nodbusiness** |
| **Social Features** | None (apps only) | Native: feed, follows, chat, reviews, discovery | **Nodbusiness** |
| **Payments** | Shopify Payments (global) + local | Stripe + Chapa/M-Pesa/Telebirr + COD + Wallet | **Nodbusiness** (local) |
| **Pricing** | $29–$299/mo + 2% transaction | $19–$99/mo + 1-3% transaction | **Nodbusiness** |
| **African Market** | Limited (no local payments, no M-Pesa) | Native: M-Pesa, Chapa, Telebirr, COD | **Nodbusiness** |
| **Developer Ecosystem** | Mature (App Store, 8000+ apps) | Building (Marketplace, quality-adjusted share) | **Shopify** (now) |
| **AI/ML** | Shopify Magic (basic) | AI Pricing (PATENT 1), Quality Share (PATENT 2), Discovery (PATENT 3) | **Nodbusiness** |
| **External Data** | None (Metafields only) | PATENT 4: Live external API binding | **Nodbusiness** |

**Verdict:** Shopify wins on ecosystem maturity. Nodbusiness wins on social-commerce integration, African market fit, and patented differentiation.
