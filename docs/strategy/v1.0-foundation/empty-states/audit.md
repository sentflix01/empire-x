# Empty States — Audit

## What Is an Empty State?

When a user visits a page that has no data yet — no posts in feed, no products listed, no messages, no orders — they see an empty state. This is one of the highest-impact UX moments in any app. It's an opportunity to guide the user toward their first action, not show them a blank screen.

## Global Standard Empty State Structure

```
[Illustration or Icon]
[Primary Message]        ← What is empty, in plain language
[Secondary Message]      ← Why it might be empty + what to do
[CTA Button]             ← The single action that fixes the emptiness
```
