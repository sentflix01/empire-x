# lib/response.ts - Success Response Helpers

## 1. What is this?

**Shared frontend library.** Small typed wrappers around res.json/status for consistent success envelopes in newer routes.

## 2. Why does it exist?

Small typed wrappers around res.json/status for consistent success envelopes in newer routes. Complements apiError (which owns failures). Prefer over raw res.json in new code.

## 3. What does it do?
