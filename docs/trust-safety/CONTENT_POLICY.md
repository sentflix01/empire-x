## 1. Purpose & Scope

This Content Policy defines what content is allowed, restricted, or prohibited on the Nodbusiness Platform. Applies to all UGC across all surfaces: showrooms, marketplace, social feed, messages, reviews, profiles, marketplace listings.

---

## 2. Universal Standards

### 2.1 Zero Tolerance (Immediate Removal + Permanent Ban + Report)

| Category | Description |
|----------|-------------|
| **CSAM** | Any sexual content involving minors |
| **Terrorism/Extremism** | Promoting violent extremist ideologies |
| **Exploitative Sexual Content** | Non-consensual intimate imagery, deepfake porn |
| **Severe Violence/Gore** | Graphic violence, beheadings, torture |
| **Human Trafficking** | Recruitment, exploitation, sale of humans |

### 2.2 Prohibited Content (Removal + Account Action)

| Category | Definition | Examples |
|----------|------------|----------|
| **Hate Speech** | Attacks on protected groups | Slurs, dehumanization, calls for violence |
| **Harassment/Bullying** | Targeted abuse, intimidation, stalking | Doxxing, coordinated attacks, threats |
| **Violence/Threats** | Credible threats of physical harm | Death threats, weapon photos with threats |
| **Illegal Goods/Services** | Prohibited by law | Drugs, weapons, counterfeit, stolen goods |
| **Financial Fraud/Scams** | Deceptive schemes for financial gain | Ponzi, advance-fee fraud, phishing |
| **Non-Consensual Sexual Content** | Revenge porn, deepfakes, hidden camera | Leaked nudes, AI-generated sexual content |
| **Self-Harm Promotion** | Encouraging suicide, eating disorders | "How to kill yourself", pro-ana content |
| **Dangerous Activities** | Instructions for harmful acts | Bomb-making, dangerous challenges |
| **Coordinated Inauthentic Behavior** | Bot networks, coordinated manipulation | Bot networks, vote brigading |

### 2.3 Restricted Content (Label/Reduce/Warning)

| Category | Handling |
|----------|----------|
| **Adult/Sexual** (Consensual) | Age-gate (18+), blur, not in discovery |
| **Graphic Medical/Gore** (Educational) | Blur, warning label, opt-in |
| **Political Content** | Label, reduce during elections, no targeting |
| **Controversial/Sensitive** | Label "Sensitive", user opt-in |
| **Alcohol/Tobacco/Gambling** | Age-gate (18+/21+), geo-restrict |
| **Medical Claims** | Unverified labeled "Unverified", link to source |

### 2.4 Allowed with Conditions

| Content Type | Conditions |
|--------------|------------|
| **Business Promotion** | In showroom/marketplace only |
| **Affiliate Links** | Disclosed, relevant, not deceptive |
| **User Reviews** | Verified purchase only, no rating incentives |
| **Political Speech** (Personal) | In profile/bio, not feed spam |
| **Religious Content** | Personal expression, not proselytizing |
| **Artistic Nudity** | Artistic/educational, non-sexual, age-gated |

## 3. Content-Type Specific Policies

### 3.1 Showroom & Business Pages

| Requirement | Violation Consequence |
|-------------|----------------------|
| **Accurate Business Info** | Name, address, contact, hours current | Warning → Suspension |
| **Product Accuracy** | Images, descriptions, prices match reality | Removal + Warning |
| **No Prohibited Products** | Weapons, drugs, counterfeit, regulated | Removal + Account Action |
| **Authentic Imagery** | Real photos of actual products | Removal + Warning |
| **Clear Pricing** | No hidden fees, bait-and-switch | Removal + Warning |

### 3.2 Marketplace Listings (Templates, Widgets, Integrations)

| Requirement | Violation Consequence |
|-------------|----------------------|
| **Accurate Description** | Features match functionality | Removal + Warning |
| **No Malicious Code** | No backdoors, data exfiltration | Permanent Ban + Report |
| **IP Compliance** | Original or licensed assets | Removal + DMCA |
| **No Deceptive Pricing** | Clear pricing, no hidden fees | Removal + Warning |
| **Compatibility Claims** | Tested on stated versions | Removal if False |

### 3.3 Posts, Feed & Social Content

| Content Type | Policy |
|--------------|--------|
| **Text Posts** | General prohibited content rules |
| **Images/Videos** | Visual policy + CSAM scanning (PhotoDNA/PDQ) |
| **Links** | No phishing, malware, illegal sites (Safe Browsing) |
| **Mentions/Hashtags** | No coordinated harassment/brigading |

### 3.4 Messages (Chat)

| Type | Policy |
|------|--------|
| **Private DMs** | E2E encrypted; no proactive scanning; user reports only |
| **Group Chats** | Same as posts; admin moderation tools |
| **Broadcasts** | Business-to-customer; same as posts |
| **File Sharing** | Max 50MB; type validation; malware scan |

### 3.5 Reviews & Ratings

| Violation | Action |
|-----------|--------|
| **Fake Reviews** (bought, incentivized, bot) | Remove + Account Action |
| **Review Manipulation** (gating, swapping) | Remove + Account Action |
| **Defamatory/False** | Remove if proven false |
| **Off-Topic** | Remove (not a review) |

### 3.6 Marketplace Developer Content

| Requirement | Violation Consequence |
|-------------|----------------------|
| **Security** | No malware, backdoors, data theft | Permanent Ban |
| **Functionality** | Works as described | Removal + Warning |
| **Licensing** | Clear license terms | Removal + Warning |
| **Updates** | Timely security updates | Warning → Suspension |
| **Support** | Documented support level honored | Warning → Suspension |

## 4. Intellectual Property

### 4.1 Copyright (DMCA)

| Process | Timeline |
|---------|----------|
| **Valid Notice** | Acknowledge <24h |
| **Removal** | <48 hours |
| **User Notification** | <24h (with counter-notice info) |
| **Counter-Notice** | Accept, forward to claimant |
| **Restoration** | 10-14 days if no lawsuit |
| **Repeat Infringer** | 3 strikes → Termination |

### 4.2 Trademark

| Process | Timeline |
|---------|----------|
| **Valid Notice** | Validate registration + scope | <4 hours |
| **Action** | Remove / Restrict / Warn | <24 hours |
| **Appeal** | 30 days | Per appeal process |

## 5. Commercial Content & Advertising

### 5.1 Platform Ads (Featured Placement)

| Requirement | Standard |
|-------------|----------|
| **Clear Labeling** | "Sponsored" / "Featured" badge |
| **Truthful Claims** | No misleading, substantiated |
| **Targeting** | No sensitive categories (health, politics, children) |
| **Landing Page** | Functional, matches ad, no malware |

### 5.2 Business Self-Promotion

| Channel | Rules |
|---------|-------|
| **Showroom** | Full control |
| **Social Feed** | No spam; relevant, valuable, non-repetitive |
| **Messages** | Only to followers/customers; opt-out respected |
| **Reviews** | Never solicit specific ratings; no incentives |

### 5.3 Affiliate/Referral Links

| Requirement | Standard |
|-------------|----------|
| **Disclosure** | Clear "Affiliate Link" / "Referral Link" |
| **Relevance** | Relevant to content context |
| **No Deception** | Not disguised as organic |

## 6. Platform-Specific Rules

### 6.1 Nodbusiness Platform

- **Single Account** per person/business
- **Real Identity** for businesses (verification for commerce)
- **No Automation** without API access
- **API Use** requires Developer Agreement + rate limits

### 6.2 Embedded Content (Widgets, Iframes)

- **Same Policy** applies
- **No Auto-Play** audio/video
- **Responsive** design required
- **No Cookie Syncing** without consent

## 7. Enforcement Actions

| Action | Trigger | Duration | Appeal |
|--------|---------|----------|--------|
| **Content Removal** | Policy violation | Permanent | Yes |
| **Warning** | First minor offense | Record only | N/A |
| **Feature Restriction** | Repeat abuse | 24h-30d | Yes |
| **Temporary Suspension** | Severe/repeat | 24h-30d | Yes |
| **Permanent Ban** | CSAM, terrorism, severe fraud | Permanent | Yes (30d) |
| **Shadow Ban** | Spam/bot behavior | Until stops | No (auto-review) |
| **Verification Required** | Suspicious activity | Until verified | Yes |
