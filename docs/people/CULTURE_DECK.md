## 4. Communication Norms

| Channel | Purpose | Norms |
|---------|---------|-------|
| **Slack** | Quick sync, alerts, fun | Threads > DMs, public > private, emoji reactions |
| **Notion** | Docs, specs, decisions, wiki | Single source of truth, keep updated |
| **Email** | External, formal, async | Clear subject, action required, 24h response |
| **Loom** | Async demos, explanations | <5 min, captions, share link |
| **Meetings** | Sync when async fails | Agenda 24h prior, notes in Notion, action items |

**Meeting Rules:**
- Default to async (Loom/Notion)
- Max 30 min default, 60 max
- Agenda 24h prior or decline
- Notes + action items in Notion
- End with clear decisions/owners

## 5. Decision Making

| Framework | When to Use | Process |
|-----------|-------------|---------|
| **Type 1 (Reversible)** | Most decisions | Decide fast, iterate |
| **Type 2 (Irreversible)** | Strategy, architecture, hiring, pricing | Write doc → Discuss → Decide → Commit |
| **Consensus** | Team norms, culture | Discuss → Consensus → Document |
| **Authority** | Crisis, legal, safety | Decide → Communicate → Execute |

**Decision Log:** All Type 2 decisions logged in Notion with: Context, Options, Decision, Owner, Date
