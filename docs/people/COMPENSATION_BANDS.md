## 1. Compensation Philosophy

| Principle | Detail |
|-----------|--------|
| **Market Competitive** | Target 50-75th percentile for role/level/location |
| **Equity Heavy (Early)** | Seed: 60/40 cash/equity; Series A: 70/30; Series B: 80/20 |
| **Transparency** | Bands published internally; no negotiation theater |
| **Equity Refresh** | Annual for top 30% performers (10-20% of initial grant) |
| **No Negotiation** | Offer = best offer; bands are the bands |
| **Internal Equity** | Compa-ratio target 0.9-1.1 |

## 3. Equity Grant Guidelines

### 3.1 Initial Grants (Fully Diluted %)

| Event/Role | Grant Range | Vesting |
|------------|-------------|---------|
| **Founders** | 15-25% each | 4yr, 1yr cliff |
| **First 10 Employees** | 0.5-2.0% | 4yr, 1yr cliff |
| **Senior Hires (L4+)** | 0.5-1.5% | 4yr, 1yr cliff |
| **Standard Hires (L1-L3)** | 0.1-0.5% | 4yr, 1yr cliff |
| **Annual Refresh (Top 30%)** | 10-20% of initial | 4yr, no cliff |
| **Promotion** | 25-50% of level delta | 4yr, no cliff |
| **Advisors** | 0.1-0.25% | 2yr, monthly vest |

### 3.2 Equity Mechanics

| Provision | Detail |
|-----------|--------|
| **Instrument** | ISO (Ethiopia/US), RSU (US/EU), Phantom (other) |
| **Vesting** | 4 years, 1-year cliff, monthly thereafter |
| **Exercise Window** | 90 days post-termination (extendable to 10yr for 5+ yr tenure) |
| **Early Exercise** | Allowed (83b election supported) |
| **Transfer Restrictions** | Right of first refusal, lockup per financing |
| **Liquidity** | Annual tender offers (post-Series A), IPO/acquisition |

## 5. Compa-Ratio Management

| Metric | Target | Action if Outside |
|--------|--------|-------------------|
| **Compa-Ratio** | 0.90 - 1.10 | <0.9: Plan adjustment; >1.1: Freeze + equity |
| **Range Penetration** | 30-70% | <30%: Accelerate; >70%: Slow |
| **Equity % of TC** | Per phase targets | Adjust at refresh |
