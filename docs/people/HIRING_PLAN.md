## 6. Hiring Process & SLA

### 6.1 Time-to-Hire Targets

| Stage | Duration | Owner |
|-------|----------|-------|
| **Requisition Approved** | Day 0 | Hiring Manager |
| **Job Posted** | Day 1 | Recruiter |
| **First Screen** | Day 7 | Recruiter |
| **Technical Assessment** | Day 14 | Senior IC |
| **Onsite/Final** | Day 21 | Hiring Manager + Panel |
| **Offer** | Day 28 | Recruiter + HM |
| **Acceptance** | Day 35 | Recruiter |
| **Start Date** | Day 45-60 | Recruiter + Ops |

**Target:** 45 days from req approval to start

### 6.2 Source Mix Targets

| Source | Target % | Channels |
|--------|----------|----------|
| **Employee Referrals** | 40% | Referral program ($2K bonus) |
| **LinkedIn/Job Boards** | 25% | LinkedIn, GitHub Jobs, Local boards |
| **Community/Events** | 15% | Hackathons, Meetups, Conferences |
| **University/ Bootcamp** | 10% | Local universities, ALX, Gebeya |
| **Agency/Headhunter** | 10% | Specialized roles only |
| **Direct Applications** | 5% | Career page |

## 6. Onboarding Program (First 90 Days)

| Week | Focus | Activities |
|------|-------|------------|
| **Week 1** | Orientation | Company mission, team intros, tools setup, security training |
| **Week 2** | Technical Onboarding | Codebase tour, dev environment, first PR |
| **Week 3-4** | First Project | Assigned mentor, small feature/bug |
| **Month 2** | Ramp Up | Own feature, cross-team collaboration |
| **Month 3** | Independence | Full ownership, mentor graduation |
| **Day 90** | Review | 90-day review, feedback, goals for next quarter |
