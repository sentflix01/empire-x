# Halehame — Convertible Note Guide

> **Classification:** Confidential
> **Purpose:** Understand convertible notes as an alternative to SAFE.
> Know when to use a convertible note vs. a SAFE.

---

## Convertible Note vs. SAFE — Quick Comparison

| Feature | Convertible Note | SAFE |
|---------|-----------------|------|
| Type | Debt instrument | Equity instrument |
| Interest | Yes (typically 5–8%) | No |
| Maturity date | Yes (typically 18–24 months) | No |
| If no priced round happens | Investor can demand repayment | Investor has no recourse |
| Complexity | Slightly more complex | Simpler |
| Common in | Older investments, bridge rounds | Pre-seed, seed, modern investors |
| Best for | When investor prefers debt protection | When speed and simplicity matter |

**Halehame recommendation:** Use SAFE for pre-seed. Use convertible note
only if an investor specifically requires it or for a bridge round.

## How a Convertible Note Works

```
Step 1: Investor gives you $100,000 as a LOAN
Step 2: The loan accrues interest at 6% annually
Step 3: The loan has a maturity date of 18 months
Step 4: When you raise a priced round (seed round):
        → The note + accrued interest converts to equity
        → At a discount or valuation cap (same as SAFE)
Step 5: If you DON'T raise a priced round by maturity:
        → Investor can demand repayment of principal + interest
        → OR they can choose to convert anyway at the cap
        → OR they can extend the maturity date (common in practice)
```

## Key Terms in a Convertible Note

### Principal
The amount invested ($100,000).

### Interest Rate
```
Typical: 5–8% annually (simple interest, not compound)
Example: $100,000 at 6% for 18 months = $9,000 interest
Total converts: $109,000 worth of equity at conversion
→ Investor gets slightly more equity because of the interest
→ This rewards them for lending money vs. the risk-free alternative
```

### Maturity Date
```
When the note must be repaid or converted.
Typical: 18–24 months from closing

What happens at maturity if no priced round:
  Option A: Note automatically converts at cap (most common, negotiate this)
  Option B: Investor demands repayment (bad for you — creates debt pressure)
  Option C: Both sides agree to extend (roll the note — common in practice)

→ Negotiate Option A or C into the note from the start
→ "Automatic conversion at maturity at the cap price" is ideal for founders
```

### Valuation Cap
```
Same concept as SAFE — maximum valuation at which the note converts.
Example: $2,000,000 cap
At conversion (seed round at $5M valuation):
  Note converts at $2M valuation → investor gets more shares
  $109,000 (principal + interest) / ($2M / total_shares) = X shares
```

### Discount Rate
```
Same as SAFE — note converts at a discount to the seed round price.
Typical: 15–20% discount
Example: Seed price $0.50/share, 20% discount → note converts at $0.40/share
```

### Change of Control
```
If the company is acquired before the note converts:
Option A: Note converts at cap before acquisition (most common)
Option B: Note repaid at 2× principal (expensive for you)
→ Negotiate: Conversion at cap on any change of control event
```

## When Convertible Notes Are Better Than SAFEs

```
1. Investor is located in a jurisdiction where SAFEs are not recognized
   (Some non-US investors prefer familiar debt instruments)

2. Bridge round between two priced rounds
   (Existing investors give more money via note while you close next round)

3. Investor requires the protection of maturity date and interest
   (Usually older, more conservative angel investors)

4. Legal counsel in target country recommends notes over SAFEs
   (Ethiopia or other African jurisdictions may prefer debt instruments)
```

---

## Convertible Note Red Flags

```
🚩 Maturity date shorter than 12 months (creates rushed fundraising)
🚩 Interest rate above 10% (expensive debt)
🚩 No automatic conversion clause at maturity
🚩 Prepayment penalty if you want to repay early
🚩 Security interest on company assets (investor takes collateral)
🚩 Personal guarantee from founder (you are personally liable if company fails)
🚩 Acceleration clause allowing immediate demand on any default event
   (Be careful — "default" can be broadly defined)
```
